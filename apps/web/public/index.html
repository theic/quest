Install Quest from a zip

  1. Download the zip
  2. Unzip it. You get a folder named quest-extension.
  3. Open chrome://extensions in Chrome and turn on Developer mode (top right).
  4. Click Load unpacked and choose the quest-extension folder.
  5. Pin it from the puzzle icon, so you can see when Quest is reading.

Then open the Connect Chrome link Quest sent you in Telegram, in Chrome.

A copy from a zip doesn't update itself the way the Web Store's does.
